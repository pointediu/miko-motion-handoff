# 领奖弹窗 · 贴纸揭晓

贴纸保持原有贴合动作；按钮在贴平前480ms开始淡入、轻抬回弹，与贴纸同时停稳，然后柔和的蓝光和白星显现、停留、淡出。节奏参考轻弹星光，特效更淡，无描边。

- 0–1400ms：原有贴纸贴合动作保持不变。
- 920–1400ms：参考轻弹星光：按钮提前480ms淡入、Y16→−2→0、缩放0.94→1.025→1，与贴纸同时停稳。
- 1400–1850ms：贴稳后蓝光、白星同时渐亮，强度调淡。
- 1850–2600ms：柔和停留。
- 2600–3400ms：缓慢淡出，停在原稿终态。
