# 领奖弹窗 · 手绘闪光

遮罩先淡入，40ms后弹窗开始弹出；接近最大尺寸时白色粗短线迸出，在峰值附近形成漫画强调。按钮在回落开始后淡入轻抬，与弹窗680ms一起停稳；按钮不再额外回弹，线条略提前收尾。

- 0–120ms：遮罩先渐暗，提前建立层次。
- 40–280ms：弹窗快速弹出至1.10倍、Y−24pt。
- 210–296ms：6根粗白线在弹窗接近峰值时迸出，强调同一个发力点。
- 280–680ms：弹窗只回落一次，平滑回到原位。
- 360–680ms：按钮稍后淡入、上移10pt、缩放0.98→1，与弹窗一起停稳，不另做回弹。
- 约290–630ms：白线向外缩短、变细并消失，略早于主体落定。
- 680–1100ms：完整终态停留。
