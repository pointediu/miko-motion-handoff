# 领奖弹窗 · 盖章星光

整张弹窗图片从稍高处倾斜靠近，像盖章一样压下、轻轻回正贴稳；随后出现与轻弹版相同的淡蓝光晕和白色星星。 底部按钮不包含在整图中，320ms 开始独立淡入轻抬并微回弹，800ms 与弹窗同时停稳，随后出现光晕和星星；蓝光与白星略增强。

- 0–460ms：整图从 1.18 倍、Y −65pt、−5° 靠近；460ms 压到 0.975 倍、Y 3pt。
- 460–800ms：轻微释放到 1.012 倍，再回到 1 倍，贴稳停住；投影同时消失。
- 800–2800ms：沿用轻弹版完全相同的淡蓝光晕、白色星星与显现/停留/淡出节奏。
- 320–800ms：查看奖品按钮透明度0→1，Y16→−2→0pt，缩放0.94→1.025→1；完成后可点击。
