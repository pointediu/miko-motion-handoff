# 领奖弹窗 · V5 整张弹窗贴合

整张领奖弹窗像一张柔软贴纸，从左上方倾斜靠近；上缘先贴住，下缘仍翘起，再从上到下压平，投影随贴合收拢。文字、奖品和按钮随同一张纸弯曲，最终回到原稿布局。

- 0–480ms：整张弹窗从左上方（−46 / −128pt）、−11°、1.08 倍靠近；上缘落在最终位置。
- 480–620ms：上缘先接触，贴合线从 0 推进到 6%，下缘保持翘起。
- 620–1380ms：贴合线自上而下推进；卷曲角从 74° 收到 0°，悬空投影同步消失。
- 1380–1500ms：停在原稿终态；按钮与关闭入口可操作。
- 内容策略：所有内容印在同一张纸上，随整张弹窗一起形变，不做独立弹跳或彩纸。

Swift 文件提供可编译的轨道采样和卷曲投影参数；开发端将完整弹窗渲染为纹理后用 Canvas 绘制，终态切回原交互视图。没有添加独立图片动效。
