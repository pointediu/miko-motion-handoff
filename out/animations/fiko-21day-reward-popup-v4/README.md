# 领奖弹窗 · V4 弹跳展开

较短的白色圆角矩形弹跳入场，清晰展示「连续打卡已达标」并停留片刻；原文案随展开移到弹窗顶部，最后按钮轻抬并小幅回落。图片固定在内容区。

- 0–520ms：196 × 68pt 圆角矩形从下方弹跳入场；圆角 20pt，显示「连续打卡已达标」。
- 520–760ms：停稳后保持 240ms，矩形尺寸和达标文案不变。
- 760–1140ms：展开到原稿 321 × 415pt、圆角 32pt；达标文案持续可见，并随展开移至原稿顶部位置。
- 1060–1220ms：奖品名称轻移淡入；图片只随容器显现，不单独动。
- 1120–1480ms：按钮淡入并上移 12pt，轻抬至 −1.5pt、缩放至 1.02 后回落到 1；只一次，不循环。
- 参考与改编：保留参考 Toast 的上冲回落节奏，加入短矩形停留、展开与达标文案连续过渡。
- 总时长：1500ms；1480ms 视觉落定。

JSON 用毫秒，Swift 参数用秒。浏览器保持原有重播、暂停恢复与关闭交互。Swift 参数不包含业务页面；Canvas 关键帧是原生渲染验证，不是浏览器截图。
