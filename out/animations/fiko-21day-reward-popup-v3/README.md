# 领奖弹窗 · V3 淡入缩放

完整弹窗轻柔淡入并由 94% 放大到 100%；两行文字依次轻移显现，按钮稍后落定。图片只随容器显现，不做独立动效。

- 0–420ms：遮罩淡入；弹窗透明度 0→1，整体缩放 0.94→1，无回弹。
- 100–500ms：说明先上移 6pt 显现，奖品名错后 80ms、上移 8pt 显现。
- 340–680ms：按钮淡入，上移 10pt，缩放 0.98→1 后停稳。
- 图片：原图位置、尺寸、角度不单独变化；只随整个弹窗淡入缩放。
- 总时长：1500ms；680ms 视觉落定，余下时间停留。

JSON 用毫秒，Swift 参数用秒。浏览器保持原有重播、暂停恢复与关闭交互。Swift 参数不包含业务页面；Canvas 关键帧是原生渲染验证，不是浏览器截图。
