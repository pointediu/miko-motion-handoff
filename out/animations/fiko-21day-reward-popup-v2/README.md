# 领奖弹窗 · 奖品贴纸贴合

在交付页「21天活动」中选择「领奖弹窗 · V2 贴纸贴合」，与第一版并列。独立预览 index.html 可离线打开，全部素材内嵌。

## 节奏

- 0–420ms：沿用第一版的弹窗和文字入场。
- 300–600ms：奖品从左移 40pt、上移 18pt 的位置靠近；起始倾斜 −12°、缩放 1.12 倍。
- 600–720ms：上缘接触并短暂停留，贴合 0→4%，纸面翘起 88°。
- 720–1320ms：贴合推进至 84%（1160ms），再压平至 100%；阴影逐渐收拢消失。
- 1320ms：阴影消失，贴平；1400ms 按钮落定，1500ms 播放停止。
- 无彩纸、无奖品缩放回弹，最终布局和素材沿用已确认稿。

## SwiftUI

parameters.json 使用毫秒。RewardPopupStickerParameters.swift 使用秒，给出完整轨道与纸面卷曲采样。StickerApplyArtwork.swift 是可复用奖品图层；将 PrizeSticker.png 导入 Assets 并命名 PrizeSticker。

传入统一 elapsed 秒数，外层按参数绘制原弹窗。顶部固定的部分保持原位置；底部用 Canvas 60 条切片表达纸面弯曲，贴平后直接绘制整张原图。减少动态效果时跳过卷曲。默认浏览器仅派发 reward:view-prize，奖品详情跳转需由业务接入。

网页和 SwiftUI 采用相同几何采样；平台的阴影模糊渲染可能有细微差异。本目录不含完整 Xcode 工程。1.32s 一次 light impact 为可选建议，网页不触发。

第一版保留原文件，不随此方案修改。当前为待确认方案，本地交付，未发布。浏览器实际画面和真机体验仍待确认。
