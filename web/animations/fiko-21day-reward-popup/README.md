# 21天活动 · 领奖弹窗

## 预览

在交付页左侧展开「21天活动」，选择「领奖弹窗」。点击「重播 / 刷新」可重播，点击「打开单页」可独立查看。也可以直接打开本目录的 index.html，全部素材已内嵌。

关闭弹窗后，点击原活动页右上角礼物图标再次打开。「查看奖品」保留按压反馈，派发 reward:view-prize 事件；正式奖品详情由业务接入。

## 动效

- 总时长 1.5 秒，完成后静止。
- 弹窗 0–420ms 入场，贴纸 180–800ms 轻弹。
- 12 片浅色彩纸从 360ms 分三组散开，1500ms 全部消失。
- 按钮 500–800ms 出现并落定。
- 减少动态效果：180ms 淡入最终状态，跳过位移、缩放、旋转和彩纸。

布局及图像来自 Figma CjLvBzUqSgYA2qFWtGYxOs 的 37:28417；原稿没有动画轨道，动效为此次新制作。

## SwiftUI

- 页面右侧已有完整时间轴、布局尺寸与「复制 SwiftUI 参数 JSON」。
- parameters.json：网页采用的同一份时序与粒子参数，时间以毫秒表示。
- RewardPopupParameters.swift：等价 SwiftUI 参数与采样函数，时间以秒表示。传入统一 elapsed 时间，pose(at:) 返回各图层状态，particles(at:) 返回 Canvas 粒子状态。
- 参数文件已通过 macOS Swift 编译检查；这里不包含完整 Xcode 工程，也未验证真机触感。
- 480ms 一次轻触感是研发建议；网页预览不会触发触感。
